Projects

Research and applied work, from lab prototypes to field-deployable systems.

Ocular Emotion Recognition

State-space (Mamba), spiking-neural and tree-based models built on gaze and pupil dynamics for real-time affective computing.

Real-Time Pose-Controlled Gaming

A real-time human pose estimation framework for gesture-based Subway Surfers control, integrating posture analysis, emotion recognition, and fitness tracking with lightweight models for low-latency interaction.

AI-Based Forest Fire Spread Modeling

A hybrid AI and agent-based framework combining U-Net fire-risk prediction at 30m resolution with NetLogo cellular automata for multi-timescale fire-spread simulation and what-if analysis.

PPG Signal Analysis

Signal processing and machine learning for PPG-based physiological monitoring, including noise reduction, preprocessing, feature extraction, and respiration analysis using Fourier and wavelet methods on the BIDMC dataset.

GPS-Denied Autonomous Landing

A vision-based autonomous navigation and landing system for quadcopters using stereo cameras and onboard perception in GPS-denied environments.

Virtual Fence

A real-time maritime safety system combining Haversine-based geofencing and ML-based Kalman filtering for vessel trajectory prediction and boundary-proximity alerts.

Smart Elector Validation System

An offline-capable biometric authentication pipeline for polling officers and booth agents, with no network dependency.

Uzhavu

A direct-to-retail agricultural supply chain model designed to give farming communities a fairer, more transparent market.
